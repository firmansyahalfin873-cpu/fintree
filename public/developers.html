QUICKSTART

Create a checkout session.

Your integration path

  1. Prepare the testnet service. Configure and start the local Base Sepolia service before using the API.
  2. Connect and get a key. Open the testnet workspace, connect your wallet and save your test API key.
  3. Create a checkout. Run the server-side example below and open the returned checkout link.
  4. Track the payment. View its status in the workspace; add a webhook when your server is ready to receive events.

Opening checkout and confirming an on-chain payment are separate steps. Test tokens and network gas are required to pay.

Open API keys ↗

From the Fintree project root, run this server-side example with your test API key in FINTREE_API_KEY. The local testnet service must be configured and running first; the separate local simulation does not expose this API.

create-checkout.mjs
import { FintreeClient } from './src/sdk/index.mjs';

const client = new FintreeClient({
  apiKey: process.env.FINTREE_API_KEY,
  baseUrl: 'http://127.0.0.1:4174/'
});

const session = await client
  .createCheckoutSession({
    orderId: 'order-1042',
    amount: '100',
    feePayer: 'merchant'
  }, {
    idempotencyKey: 'order-1042'
  });

console.log(session.checkoutUrl);
Server-side exampleFintree SDK

Use a unique idempotency key per order. Keep API keys on your server, never in browser code.

PAYMENT LIFECYCLE

Know where a payment stands.

Fintree verifies payment data independently before marking a session as paid.

PendingThe request is waiting for payment.
ConfirmingA matching payment is awaiting confirmation.
PaidThe payment passed verification.
ExpiredThe request expired without a confirmed payment.

WEBHOOKS

Keep your systems in sync.

Configure an HTTPS endpoint in the testnet workspace. Verify the signature against the original request bytes before processing the event, and use the event ID to handle repeated deliveries.

verify-webhook.mjs
import { verifyWebhook } from './src/sdk/index.mjs';

// rawBody is the original Buffer from your HTTP request.
const valid = verifyWebhook(
  rawBody,
  request.headers['x-fintree-signature'],
  process.env.FINTREE_WEBHOOK_SECRET
);

if (!valid) throw new Error('Invalid signature');

CURRENT AVAILABILITY

Build with the right context.
