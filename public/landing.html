GOOD TO KNOW

Questions, answered.

Everything you need to start exploring.

Do I need real funds to try Fintree?＋

No. The local simulation uses a local chain and simulated assets. Base Sepolia testing requires separate test assets.

Which tokens and networks are supported?＋

The current testing focus is test USDC on Base Sepolia. Other tokens and networks are not yet supported.

Is Fintree ready for production?＋

Not yet. Fintree is an experimental prototype and has not been audited.

How do I try a payment?＋

Open the dashboard, create a test payment, then follow the checkout in your current environment.
