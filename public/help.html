HELP TOPICS

Answers, without the guesswork.

What can I use Fintree for today?＋

Fintree is in development. You can explore the local payment flow and a configured Base Sepolia testnet service. It has not been independently audited and is not ready for real funds.

Which network and token are supported?＋

The current testnet target is Base Sepolia with a configured six-decimal test token. Support for other tokens and networks has not been verified.

How do I create a payment request?＋

Open the workspace, enter an order reference and amount, choose who covers the protocol fee, and create the payment. In the testnet workspace, connect a wallet first.

How do I share a checkout link?＋

After creating a payment in the testnet workspace, copy the checkout link or find it in recent activity. Anyone with the link can view its payment details. Local service links only work on that computer.

Why is my wallet on the wrong network?＋

The wallet must use the network shown in checkout. If prompted, use the switch-network action and approve it in your wallet. Changing networks does not submit a payment; review and confirm the payment separately.

Why can a payment take more than one wallet transaction?＋

A token approval can be needed before the payment transaction. Your wallet shows each request separately, including network gas. Review every request before confirming.

What do pending and confirming mean?＋

Pending means the request is waiting for a verified payment. Confirming means a matching payment was observed but has not yet met the configured confirmation policy. Paid means it passed that verification.

What if a payment needs review?＋

Do not try to pay again while the payment is marked for review. Contact the merchant to investigate the status and check the transaction in your wallet.

How are protocol fees and gas calculated?＋

The current test configuration uses a 0.3% protocol fee. The merchant chooses who covers it. Network gas is separate. Explore the fee calculator for an illustrative breakdown.

How should I protect my API key and webhook secret?＋

Store them securely on your server. Do not put them in browser code or share them in chat. A newly created value appears only once; you can revoke an API key from the workspace.

What happens when I disconnect the workspace?＋

The page clears its active workspace session. This does not disconnect your wallet extension or revoke issued API keys; manage those separately.

Where can a developer start integrating?＋

Start with the developer guide for the checkout example, payment statuses and webhook signature verification. The current API is limited to test environments.
